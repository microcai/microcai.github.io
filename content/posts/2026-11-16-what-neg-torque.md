# 负扭矩是什么

扭矩有方向。让电机正转的扭矩，就是正扭矩。
让电机反转的扭矩，就是负扭矩。
同理，正转的时候，就是正转速。
反转的时候，就是负转速。

$$
电机输出的机械功率 = 扭矩 \times 转速
$$

因此，

$正扭矩 \times 负转速 = 负功率$

$负扭矩 \times 正转速 = 负功率$

所谓负功率，说明电机在吸收机械功率。能量是守恒的，他吸收的机械功率，就要变成电能。

因此，我们说负功率下，电机在发电。

通常，电机正转时，输出负扭矩，就是在发电。

是这样的吗？

# 负扭矩会发电吗？

电机带着负载高速正转时，如果要求电机输出负扭矩，就是主动对负载减速，然后反转。
在这个过程中，电机会先发电，然后耗电。

因为，反转后，$负扭矩 \times 负转速 = 正功率$

但是，并不是减速到0后开始反转电机才耗电，在接近0转速的时候，电机就已经退出发电状态进入耗电了。

这里面的机制是这样的：

1. 电机带着负载高速正转时，输出负扭矩靠的是，控制器输出比反电动势低的电压，迫使反电动势让电流倒转 —— 电流从电机流向直流母线，然后进入电池。
2. 随着转速的下降，反电动势越来越低，如果还靠吸收反电动势产生负扭矩是不够的。因此电机此时通过反转来输出负扭矩。所以，在接近0转速的时候，电机就已经退出发电状态进入耗电了。

3. 最后转速到0，乃至开始反转，电机就彻底的负扭矩+负转速了。负负得正，耗电是理所当然的啦。

这里面难理解的地方，就在于，为何正转+负扭矩不一定会发电？

# 发电这个事情

我们断开控制器，就只保留电机。把电机转起来，电机的线圈就会切割磁感应线。天然的就会发出电压。

$$发电电压 = 转速 \times 磁通量$$

接上负载就会发电。

但是，他发出的电压，正比于转速。
意味着：当他接入电源当电动机用的时候，只有发的电压超过电源，能量才能反向流回电源。而他发电等于电源电压的转速，恰好就是空载转速。

只有超过空载转速才能发电啊！

发电才能输出负功率。所以电机不超过空载转速不能输出负功率？

非也。

控制器是可以对电机发出的电进行升压的。

当控制器输出 三相全低电压 时，3个桥臂的下管一起导通。这等于直接短路了电机的绕组。
于是，电机发出来的反电动势，就会直接作用于电机的绕组，是的绕组的电流提高。
接着，MOS管关闭。电感电流不能突变！于是，电流需要强行流过，咋办？ 自然就是冲破MOS自带的体二极管，于是电流就从电机流向直流母线，然后进入电池。为何一定要这么流？ 因为6个体二极管的方向决定了，只能这么流。

所以， 控制器只要不断的 三相短路-开路，就可以实现电机的发电。不需要电机发的电压高于母线电压。控制短路的时间占比就能控制发电功率，也就是控制负扭矩。

但是，这并不是实现负扭矩的方式。

我们来看，这种方式有什么问题。

1. 他在低速下，无法实现大的负扭矩。<br>
   低速下，电机的反电动势就小，即便100%短路三相绕组，也不足以产生足够的电流。于是，低于某个转速后，想要的负扭矩就无法维持了。

2. 他无法自然的通过反扭矩实现反转。<br>
   最终转速到 0 后，控制器必须重新切换到驱动模式，才能实现反转。

当然，第二个问题恰恰是它能被广泛使用的原因：它绝对做到了，只提供制动扭矩，不会把刹车变成反转是他的核心竞争力。

如果你要负扭矩的目的是刹车，那么这种方式就非常的靠谱。只需要接受一个缺点：低速的时候刹车力度就不足了。

# 低速下维持负扭矩

从他 100% 短路三相绕组也维持不了足够的刹车力度的时候，就已经告诉了你，想维持负扭矩，必须费电了。

也就是说，需要主动的制造滞后转子90°的定子磁场了，靠这种电磁阻力刹车已经不行了。

所以，当控制器发现，短路占空比已经到了 100% 了，电流还是不够。就要切换到驱动模式了。

# 切换来切换去，麻烦

其实，如果使用矢量控制，并不需要切换！他完全可以实现，任意转速（包括低速，负转速）下的负扭矩。
过程丝毫不涉及任何模式切换。

这是为什么呢？

我们先来看，在高正转速下，要求输出负扭矩，控制器到底输出了啥。

我们把转子的方向，设定为 D 轴。如果要正扭矩，我们让定子的磁场，指向 Q 轴。
于是，转子就会往 Q 轴旋转。这就是 正扭矩。为了让定子的磁场指向 Q 轴，我们让定子的电压，指向 Q 轴。

因此，在正转+正扭矩的时候，我们输出的是正的Q轴电压。

问题在于，正转+负扭矩的时候，我们输出的是负的Q轴电压吗？

不是。

因为反电动势本来就顶在 Q 轴上。
转速是正的，他就是正的。转速多大，他就多大。你动不了他。
于是绕组上真正说了算的，不是你的输出电压，是他的电压和你的电压的差：

$$
\begin{aligned}
& Q轴净电压 = Q轴输出电压 - 反电动势，\\
& 电流 = \frac{Q轴净电压}{绕组阻抗}
\end{aligned}
$$

电流由这个差决定。
想要正电流，就输出比反电动势高一点的电压。
想要负电流，就输出比反电动势低一点的电压 —— 是低一点，不是反过来。
只要反电动势还顶着，输出的 Q 轴电压就依然是正的。

扭矩认的是电流，不是电压。
负的 Q 轴电流，做出指向负 Q 轴的定子磁场，这就是负扭矩。
所以高转速下的负扭矩，是用正的 Q 轴电压做出来的。他比反电动势低，电流就倒流了，于是顺便发了电。

那低速呢？
反电动势掉到 0 了，减号后面没东西可减了。
这时候想要负电流，就得输出真正的负 Q 轴电压。
这就是前面说的"想维持负扭矩，必须费电"。费电就是这么费来的。

再往下，转速过 0，反电动势跟着反号。
输出跟着他一起反号，只要始终比他更低一点，电流就还是负的，负扭矩还在。
于是Q轴的电压，他从正滑入负，是一个连续的过程，中间没有断点。
没有断点，就没有模式可切换。这就是矢量控制不麻烦的原因。

这里得说清楚一件事：控制器输出的电压，是 DQ 两个轴上那个电压矢量的模长。
D 轴和 Q 轴，只是这个矢量的两个分量。
平时 D 轴电压几乎为 0，矢量就躺在 Q 轴上，所以 Q 轴的正负，就是矢量朝哪。
所以 Q 轴电压从正滑到负，改的是矢量每时每刻的方向，不是矢量的大小。

低速正转的时候，负的 Q 轴电压就是说：矢量掉头了，指着负 Q 轴。
反电动势趴在 0 上，没人帮你推电流，只能靠这个矢量主动发力，把电流硬压过去。
电压和电流同向，控制器往电机里送电，这就是耗电状态。

反过来，高转速下的负扭矩，矢量还指着正 Q 轴，只是比反电动势低一点。
电压和电流反向，电机往控制器送电，这就是发电状态。
矢量没有掉头，他只是被反电动势压着走。


# 两种模式的对比

| 对比项 | 短路刹车负扭矩 | 矢量控制负Iq产生负扭矩 |
| --- | --- | --- |
| 电流的电源是谁 | 电机自己，反电动势 | 控制器 |
| 控制器手里调的是什么 | 短路占空比，调的就是电流 | 电流的目标值，调的也是电流 |
| 电流能不能被控制 | 能。占空比从 0 拉到 100%，电流跟着变 | 能。目标值给多少，就是多少 |
| 要不要闭环 | 要。不看电流，占空比去调个啥 | 要 |
| 要不要采电流 | 要，但只看母线电流就够了 | 要，而且必须采相电流 —— 不然不知道电流矢量朝哪 |
| 电流的上限被什么封住 | 被反电动势封住。占空比拉满，也不过就是短路电流 | 被母线电压封住，跟转速无关 |
| 电流的方向由谁定 | 反电动势的极性加体二极管，你选不了 | 目标值的正负号，你说了算 |
| 扭矩和转速 | 力可以调，但可调的范围被转速绑死 | 脱钩。0 转速、负转速照样给 |
| 能不能反转 | 不能。转速到 0 必须切回驱动模式 | 能。同一个负数目标一路滑过去 |
| 有没有断点、要不要切模式 | 有断点，必须切 | 没有断点，不用切 |
| 覆盖几个象限 | 一个：正转速 + 负扭矩 | 四个 |
| 会不会把刹车做成驱动 | 不会，天生不可能 | 会，看你给的目标值是什么 |
| 要不要转子位置 | 不要。体二极管跟着反电动势自己换相 | 要 |
| 要不要摸清绕组阻抗 | 不要。闭环自己会把占空比找出来 | 要。电流环得按阻抗配 |
| 适合干什么 | 只做刹车 | 刹车、倒车、堵转、四象限全都要 |

一句话：两种模式都在控制电流，区别只在于天花板是谁给的。

短路刹车的天花板是转速给的。转速掉到 0，天花板就跟着掉到 0。
矢量控制的天花板是母线电压给的，跟转速无关。

只要刹车，前者已经够好了 —— 他连"刹车不会变成反转"都帮你保证掉了。
要四象限，只有后者给得起。

以矢量控制做制动则必须有过零检测、方向管理、零速转矩归零和摩擦制动冗余，否则“踩刹车变倒车”是真实风险。
