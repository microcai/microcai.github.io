给新事物命名，从来都是一件吃力的事。它要求你把一个全新的东西揉碎了、看透了，抓住它最要紧的那几个核心特征，浓缩成一个别人一听就懂、一看就明的词。

越是新的事物，越是难命名。因为越新，就越没有现成的词可以套用，越逼着你去动脑做真正的总结。

而总结能力，是最见真章的能力。会不会命名，本质上是会不会抓本质。

# 一、命名的本质是总结

给新东西起名字，难在哪里？难在"总结"。你面对一个从未存在过的东西，脑子里没有现成答案。你必须回答两个问题：

- 它到底是什么？
- 它最核心的那个特征，怎么用几个字说清楚？

答不好第一个问题，名字就飘；答不好第二个问题，名字就长。一个真正的好名字，一定是把这两个问题都答对之后，自然涌出来的。

汉语命名，走的就是这条路。看几个例子：

- **火车**：有火（蒸汽）的车。
- **飞机**：会飞的机器。
- **电脑**：通电的脑子。
- **手机**：拿在手里的机器。
- **电视**：用电传过来的"视"（画面）。
- **互联网**：互相连起来的网。

每一个，都是先总结出最核心的特征，再用已有的字拼出来。听到的人完全不需要查字典，一听就知道那是什么。这才是"命名"该有的样子。

# 二、首字母缩写是逃避总结

西方人在面对同样的问题时，拿出了另一套方案——首字母缩写。

这套方案分两步，两步都巧妙地绕开了"总结"：

**第一步，堆名词。** 把一个新东西的所有特征，用一长串现成的名词罗列出来。注意，是罗列，不是总结。罗列是不需要动脑子的，只需要把描述性的词一个个往上垒。

**第二步，提首字母。** 把这串名词每个词的首字母拎出来，拼成一个新"词"。

于是，命名这件事，就被"糊弄"过去了。你仔细看这两个步骤：

- 罗列描述，是**不敢总结**；
- 提取缩写，是**放弃意义**。

两头加在一起，一个全新的东西，就在没有经过任何"本质提炼"的情况下，被"命名"了——或者说，被"略过命名"了。

看看这些所谓的"名字"：

| 缩写 | 背后的描述 |
|------|-----------|
| LASER | Light Amplification by Stimulated Emission of Radiation |
| RADAR | Radio Detection And Ranging |
| SCUBA | Self-Contained Underwater Breathing Apparatus |
| LED | Light-Emitting Diode |
| GPS | Global Positioning System |
| HTTP | HyperText Transfer Protocol |
| AIDS | Acquired Immune Deficiency Syndrome |

看出来了吗？它们没有一个是"名字"。它们只是"一长串描述"被折叠之后的**索引**。

首字母并没有替它总结——首字母只是替它**略过**了总结这一步。

当你第一次看到 LASER 这个词，你能从中读出任何信息吗？不能。你读出的只是四个字母 L-A-S-E-R。它背后到底是个什么东西，你得翻开那串长长的形容短语才知道。也就是说，这个名字，对第一次听到它的人而言，是**空的**。

这恰恰暴露了本质上的无能：正是因为缺乏"抓住核心特征、凝练出一个自解释词"的能力，才不得不把总结这一步外包出去——先外包给罗列，再外包给缩写。

缩写不是总结的成果，是总结的缺席。

# 三、翻译，才是真正的首次命名

于是，一件耐人寻味的事发生了。

当一个中国人第一次面对 LASER 这种缩写，被迫要把它"翻译"成汉语的时候，西方人跳过的那一步，就落到了中国人头上。

翻译者必须做一件西方命名者始终没做的事：**搞清楚这个东西到底是什么，抓住它的本质，然后用汉字给它造一个真正的名字。**

这才是这个东西，有史以来第一次，被真正地"命名"。

看几个例子，对比就知道差距：

- **LASER → 激光**。*Light Amplification by Stimulated Emission of Radiation*，直译"受激辐射光放大"。中国人没有照抄这一长串，也没有满足于音译"镭射"，而是抓住机制——这束光是靠"受激"产生的——起了个名字叫**激光**。两个字，把原理说透了。

- **SCUBA → 水肺**。*Self-Contained Underwater Breathing Apparatus*，一长串"自包含水下呼吸装置"。中国人给它的名字是**水肺**——水里的肺。两个字，一个画面，形象到无需解释。

- **computer → 电脑 / 计算机**。中国人生出了两个名字：**电脑**（通电的脑子）、**计算机**（会计算的机器）。各自抓住了一个侧面，都比冷冰冰的 computer 更传神。

- **LiDAR → 激光雷达**。*Light Detection And Ranging*，一长串"光探测与测距"。中国人没照抄这一串，而是直接拿"激光"和"雷达"两个现成词根一拼，就成了**激光雷达**——它用什么光去探测，字面上一目了然。

哪怕是被动地"翻译"，中国人都要完成一次真正的抽象和命名。而西方这个"原创者"，反而从头到尾没有给这些东西起过一个像样的名字。

# 四、为什么西方只会缩写

原因藏在语言的基因里。

英语的构词，很难像汉语那样，随手抽出两个有意义的字根，一拼就是一个自解释的新词。

当需要给"光被受激放大"这个新事物造词时，英语面前只有两条路：

1. **古典词根拼装**：抓希腊/拉丁词根来拼，比如 dentist（牙 + 者）、television（远 + 视）。这需要深厚的古典语背景，而且拼出来的词对普通人依然不透明——今天还有多少人能一眼看出 dentist 里藏着个"牙"、television 里的 tele 是"远"？

2. **首字母缩写**：把一长串现成名词的首字母掐下来。这条路门槛最低，不需要任何古典修养，于是成了默认路线。

而汉语呢？直接写**激光**两个字，完成。每个字都认识，每个字都表意，拼起来还自动自解释。

这就是为什么西方越来越依赖缩写——不是它不想造好词，而是它缺乏一套"用常用字自由拼出透明新词"的机制。缩写不是天赋，是拐杖；不是先进，是凑合。

更妙的是，当缩写泛滥到一定程度，连"缩写对应什么描述"都被遗忘了。Wi-Fi 这种词，根本不是什么缩写，而是商标硬拗出来的一个"听起来像缩写"的假词。很多从业者自己也背不出 HTTP 的全称。缩写一旦脱离了它缩写的那个描述，就彻底变成了无意义的字母垃圾。

# 五、西方偷懒命名法之二：直接拿人名命名

其实，缩写还算"动了点脑子"的偷懒——它好歹把一长串描述压在下面当垫子。西方还有一门更彻底的懒法：**直接拿人名命名**。

拿人名命名，除了告诉你"这是谁弄出来的"，其余信息一概归零。人名是个纯粹的标签，跟事物本身的任何特征都无关。

- **毕达哥拉斯定理**（Pythagorean theorem）。光看这名字，你会知道它跟三角形有关吗？会知道"直角三角形两条直角边的平方和等于斜边平方"吗？全然不会。它只告诉你：有个叫毕达哥拉斯的人。（顺带一提，这定理根本不是毕氏最早发现的，古巴比伦人、古中国人老早就知道了。）

- **康达效应**（Coandă effect）。光看这名字，你会知道它讲的其实是流体的**附壁效应**——流体流过曲面时，会被"吸"着贴着壁面走吗？不会。"康达"只是那个人名的译音，跟"流体贴壁跑"这件事半毛钱关系都没有。

对比汉语的译名：

- 毕达哥拉斯定理，汉语的老名字叫**勾股定理**。勾、股是两条直角边，弦是斜边——三个字把直角三角形的结构画得一清二楚，还自带"勾三股四弦五"的口诀。
- Coandă effect，汉语的正式名是**附壁效应**。四个字，现象直接摆在眼前。

看出来了吧？西方人起名，是能懒就懒：堆砌名词就缩写，懒得缩写就搬人名。两门懒法，一路货色。而汉语每次接手，都又是一次货真价实的命名——"翻译才是真正的首次命名"，这里又多出两个铁证。

# 六、汉语为什么也开始借缩写

有一种反驳，看似很有道理：你说汉语最会造词，可今天的汉语里，不也到处是 LED、CPU、HTTP、AI、PPT、KPI？凭什么说汉语更会命名？

这正是最值得深挖的地方——汉语不是没这份本事，而是在一天天**放弃这份本事**。

先看看老一辈是怎么干的。徐光启译《几何原本》，把 point 定作"点"、line 定作"线"、surface 定作"面"，又把 geometry 定作"几何"。几百年过去，这些字无人能替代。钱学森把 laser 从生硬的音译"镭射"里捞出来，定名"激光"。还有软件、硬件、鼠标、键盘、显示器、互联网、手机、机器人——哪一个不是前人绞尽脑汁、一个字一个字"造"出来的？

在那个年代，翻译是一件顶要紧的圣事。译者为了一个词能翻来覆去琢磨几个月，造出来的名字，要经得起老百姓念、经得起时间磨。他们把"给新事物起个好名字"，当成了一种手艺、一种责任。

到了今天的新一代从业者这里，画风全变了。

面对一个刚冒出来的缩写，他们不再费心去造名字，而是**原样拿来**，嘴上念字母、笔下写英文。AI 就是 AI，为什么不叫"人工智能"？PPT 就是 PPT，为什么不叫"演示文稿"？KPI 就是 KPI，为什么不叫"绩效考核"？

是他们造不出来吗？不是。是他们**懒**了。

造名字是件"吃力"的事：你得先吃透这东西是什么，再提炼出本质，再去翻找恰当的字，还得冒"造得不好被人笑话"的风险。而直接抄一个缩写，零成本、零风险，还显得"洋气""专业"。

举个例子。 CORDIC（Coordinate Rotation Digital Computer），我绞尽脑汁，给它想了个新名字——**旋转切分机**。

这名字不是拍脑袋来的。西方人自己就造过"差分机""分析机"，汉语里给这类机器起名，早有"XX 机"的老套路——差分机、分析机、计算机，一路下来都是这么叫的。既然它也是个"机"，我就顺着这个路数，先给它安上一个"机"字。

"机"字有了，前面填什么？我就去抠它的本质。这算法的每一步，都是绕固定角度 arctan(2⁻ⁱ) 转一下——把要转的大角度，像切蛋糕一样，一刀一刀切成 arctan(2⁻ⁱ) 的小块，然后一小块一小块地旋过去，直到逼近目标。

旋转、切分，两个动作就是它的全部。于是"旋转切分机"水到渠成：它怎么干活、为何算得又快又准，全写在了名字里。这才是命名。

但是业界继续念 CORDIC，或者把洋人那串堆砌的"坐标旋转数字计算机"一个字一个字直译过来。

注意这个"坐标旋转数字计算机"——它压根不是名字，只是把洋人的堆砌（坐标 + 旋转 + 数字 + 计算机）换成汉字，原样重抄了一遍。抄的还是那堆名词，一行总结都没有。真正抓住本质的"旋转切分机"，反而被晾在一边。翻译这门手艺断代之后，行业就是这个模样：连抄带译，就是不干那件最吃力的活——总结。

可为什么"直接抄"反而显得高级？罪魁祸首，是全民强制英语教育。它干了两件致命的事：

**第一件，它把手艺人的手给废了。** 强制英语教育，让理工科从业者个个都能流利地读英文文档、用英文缩写。既然能直接看懂、直接上手，翻译就成了"多余"——从"必要"沦为"可有可无"。造名字的手艺，因为再也没人需要，而断代了。

**第二件，更阴毒的一件，它给洋缩写镀了金。** 谁张口 AI、闭口 KPI，谁就显得专业、国际化、跟上时代；谁坚持说"人工智能""绩效考核"，反而显得土气、落伍、翻译腔。于是好名字造得再漂亮，也无人喝彩，甚至反被讥笑。翻译，就这样硬生生从"圣事"变成了"蠢事"。

**吃力，又不讨好。** 一门手艺，一旦落到"吃力不讨好"的田地，还有谁会去碰它？

于是新一代从业者，理所当然地放弃了。他们不是不会命名，而是被这套教育驯化得**不想**命名、**不屑**命名。拿来主义，成了最"理性"的选择。

只是代价，由整个汉语来付。老一辈造的"激光""电脑"，至今仍在发光；而新一代手里流进汉语的新概念，越来越以字母垃圾的面目闯入。更要命的是，许多人甚至不知道"激光"是中国人自己造的——他们早已习惯了一种错觉：**好名字都该是抄来的。**

逼全民族学英语，本意或许是"接轨世界"，落到命名这件事上，却是让汉语缴了械。

# 七、洋泾浜工程师，只能是附庸

全民强制英语教育，最终造就的不是什么"国际化人才"，而是一大批**洋泾浜工程师**。

"洋泾浜"这个词不能再贴切。它本是上世纪上海租界里，苦力们跟洋人打交道时硬凑出来的一种蹩脚英语——没有自己的语法，没有自己的词汇，只会一个词一个词地模仿主家，用来换口饭吃。它是奴隶的语言，是附庸的语言。

今天的工程界，满口 AI、KPI、API、PPT 的从业者，跟当年的洋泾浜何其相似。

他们读得懂英文文档，背得下一串缩写，却再也造不出一个属于自己的词。流利地说着别人的话，哑巴似的说不出自己的话。懂是懂了，但那是一种借来的懂——是站在洋人的词汇体系里懂，不是在自家的语言里懂。

这就是洋泾浜的心态：永远等主家先开口，再跟着学舌；永远等西方先发明，再赶紧去翻译、去借用。

这种心态，比偷懒更致命。

因为命名从来不是装饰，它是**占有**的第一步。你给一样东西起了名字，才算真正攥住了它；能用自己的语言描述它、命名它、拆解它，才算真正懂了它、拥有了它。一个民族如果在命名上缴了械，就等于放弃了知识的主权。

一个只会翻译、借用、却永远不会命名的工程界，注定只能跟在西方屁股后面跑。他们造出坐标旋转算法，我们跟着叫 CORDIC；造出大语言模型，我们跟着叫 LLM；连开会用的幻灯片，都得跟着叫 PPT。我们永远慢半拍——不是技术慢，而是在概念上打从一开始就慢了一程：他们定义概念、起名字的时候，我们在等；等他们起好了，我们再翻译过来。从那一刻起，附庸的地位就定了。

更可气的是，有些东西汉语里早就有了现成的好名字，他们偏不用。就拿 Bode 图说——它画的不过是频率和增益之间的关系，玩音响的人早就给它起好了名字，叫**频响曲线**。四个字，一目了然。可工程界偏要中英夹杂地念"bode 图"，仿佛沾上这个洋名，自己就高出一等。现成的汉语名字摆在眼前都不用，这就不是"能不能译"的问题了，是"有名字也不想用"——洋泾浜当到了家。

这种事不止工程界，娱乐圈更甚。过去老一辈拍电影，把人用钢丝吊起来做高难度打斗，本来有个极贴切的名字——**吊钢丝**，三个字，谁看了都懂：拿钢丝把人吊起来。结果改革开放的春风一吹，全改口叫**吊威亚**了。

"威亚"是什么？就是 wire 的蹩脚发音——从前英国殖民地香港人，就把 wire 这么囫囵地读成了"威亚"。

一个好端端的"吊钢丝"不用，偏去学香港的洋泾浜口音叫"吊威亚"，图啥？图的正是那份"洋气"。在洋泾浜的脑回路里，沾上洋味就是高级，越洋越体面。一个耳熟能详的汉语词，就这么被一句蹩脚洋腔顶了包。

反过头来看，老一辈那批"激光""电脑""手机"，不只是几个漂亮的名字，更是中国人在概念上**当家做主**的凭证。而今天满口洋泾浜的工程师，恰恰把这份"当家"的资格给丢了。

全民英语教育之罪，不止于让人变懒；它把整个中国工程界，调教成了一群只会学舌、不敢命名、也无从命名的附庸。

# 八、结语

给新事物命名，考的是你一件事：能不能抓住本质。

西方人用首字母缩写这个法子，把这场考试变成了一张白卷——堆砌名词，提取首字母，然后宣布"命名完成"。可那几个冷冰冰的字母，什么也没说出来。

反观汉语，每一次把缩写"翻译"过来，都是一次认认真真的总结、一次货真价实的命名。**激光**、**水肺**、**电脑**、**激光雷达**——这些，才配叫名字。

命名的能力，就是总结的能力。连总结都不会，也就只配用用首字母缩写这种上不了台面的把戏了。
