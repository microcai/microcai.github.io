汉语和数学语言是同构的。

英语是"语法先行"的语言，汉语是"语义先行"的语言，而数学，是语义先行走到极致的产物。所以数学公式可以用汉语直接**念**出来，用英语却只能**翻译**。

# 语义优先 vs 语法优先

先看句子。

一个名词出现在动词的位置上，会发生什么？英语里只有两种结局：要么是病句，要么办手续——承认这个名词被转类成了动词，然后带上动词的全部形态变化。Google 本来是公司名，当了动词就得是 I **Googled** it、He **Googles** it，过去式、第三人称单数一个不能少。你说 I Google it yesterday，错的不是意思，是手续没办。

汉语呢？"百度一下"、"微信我"、"咱们火锅吧"，名词直接进动词槽，词形不变，没有任何手续。能不能这么用，靠的是语义通不通：百度是工具，可以转指"用百度搜"；桌子转指不出任何动作，所以"我桌子一下"不行。**英语像海关，词要换词性得先签证；汉语像市场，意思能听懂，词就能临时摆摊。**

这就是两种语言的根本分野：

- **英语**：形态和句法先搭好刚性模具，规定每个位置必须是什么范畴，语义再往格子里填。时态、单复数、主谓一致、冠词，全是强制的。
- **汉语**：语义关系先搭起来，形式标记极少，范畴由位置和语境临时决定。"我吃了饭"和"饭我吃了"，位置变了，语义没变。

有人拿"狗咬人 / 人咬狗"证明汉语也靠语序区分施受，这其实是犯了英语的毛病——用语法位置预设了一个现实中不存在的歧义。真实世界里狗只能咬人，语义和常识早就把施受关系锁死了，根本轮不到语序出场。英语不管这一套，Man bites dog 语法上完全合法，因为它的语法结构不关心现实，只关心形式。

# 精确到底靠语法还是靠语义？

常见的崇拜是：英语精确，因为英语语法严密。

这话经不起追问。人类手里最精确的语言是数学，而数学的语法简陋到可怜——无非是运算符、括号、变量的拼接，没有时态，没有单复数，没有冠词，没有从句嵌套。它能造出火箭、推出相对论，靠的不是语法复杂，而是**每个符号的语义被定义绝对锁死了**。

a × b = b × a。这个式子说明的是：只要"乘法"的定义里包含交换律，a 和 b 谁在前谁在后，在语义上完全等价，位置退化成了纯粹的排版问题。a × (b + c) 和 a × b + c 不同，括号改变的也是**运算次序**这个语义概念，而不是什么位置语法。数学里真正的语法错误（比如 a × + b）之所以错，是因为它对应不上任何有意义的运算——语法是为语义能被解析服务的，不是先于语义存在的规矩。

反过来看英语。它的词（符号）语义模糊，才不得不发展出繁复的语法去兜底：not all 靠位置表示部分否定，none 表示全部否定，试图用词序弥补符号组合的歧义。可这治标不治本，英语法律文书的语法繁复到极点，照样天天打官司——语法从来没有真正消灭过语义歧义。

现在再看汉语的语法，发现他实际上和数学如出一辙。句子的意思由句子用了哪些字决定，而不是用了哪些语法决定。

所谓精确，是先把概念、关系、定义想清楚，形式只是跟着语义走。语法完整、连接词齐全，制造的只是一种"看起来很精确"的假象。

# 数字符号是表意的

那数学符号到底是什么东西？我的结论是：**数学符号本质上就是简化字。**

`+` 不承载任何读音，它直接携带"加"的语义；`÷` 直接是"除"，`=` 直接是"等于"，`∴` 直接是"所以"，`∀` 是"任意"，`∃` 是"存在"。字形绕过声音，直接绑定意义——这和"水"这个字直接携带水的语义，没有任何结构上的区别。而且它们比汉字走得更远：核心符号只有几十个，一个符号只对应一个意义，没有多义，没有歧义。这是一种被设计成"低学习成本、高表意效率"的极限简化字。连公式里的字母 a、b、x 都被去拼音化了，它们不再表音，只是"甲、乙、丙"式的占位符。

英语是表音文字，字母先对应声音，声音再对应意义，中间天生没有"表意接口"。于是数学符号一进英语句子，就必须被"读出来"、翻译成词，而一旦翻成词，立刻触发英语的语法连锁反应：

- `=` 不能当词用，得翻译成动词 is / equals，还得带主谓一致。
- `>` 得翻译成 is greater than，系动词必须补上。
- `∴` 翻译成 therefore，而 therefore 是连接副词，语法禁止它和 because 在同一个句子里共存。

所以"因为 a > b，所以 a + c > b + c"在汉语里是完全合法的句子，符号 a > b 作为一个语义块直接充当"因为"的宾语；直译成 Because a > b, therefore a + c > b + c，英语语法直接判错，必须拆成两句。

更物理的冲突是空格。数学公式的语法是原子化的，符号之间不能有词边界；英语的一个概念动辄由好几个单词构成，单词之间必须有空格。把"状态转移矩阵"请进公式，State Transition Matrix 三个词往那一摆，读者立刻分不清哪些空格是乘法、哪些是词距，除非用下划线或驼峰命名给英语做非法手术。而"状态转移矩阵"六个字无空格、无形态，天然就是一个不可分割的语义原子，开箱即用地可以塞进任何公式。连乘号都欺负英语：× 和变量 x 在手写和紧凑排版里几乎无法区分，英语没有一个单字、单音节的"乘"，只能靠斜体、点乘、省略乘号这些排版补丁硬撑；汉语一个"乘"字，视觉和读音上都和 x 井水不犯河水。

明白了这一层，"数学英语"是什么就一目了然了：它是一种**协和语**——英语语法外壳加上数学符号内核，两套互不兼容的系统靠 Let...、Suppose...、where... 这些语法脚手架强行缝合。你看英语数学论文，公式永远独立居中，正文和公式之间有一道明显的语法柏林墙；而汉语论文里"由 a > b 可得 a + c > b + c"可以直接嵌进句子，一气呵成。汉语里从来不存在"数学汉语"这种怪胎，因为根本不需要。

# 数学公式和汉语的次序是一致的

"念"和"翻译"是两种完全不同的操作。**念，是把符号 1:1 映射成语言单位，结构不变；翻译，是把源结构拆散，按目标语言的语法重新组装。**

最简单的试金石：

- 公式：a + b = c
- 汉语念：a 加 b 等于 c
- 英语念：a plus b equals c

汉语这边是严格的一一对应：a 对主语，"加"是谓语动词，b 是宾语，"等于"又是谓语动词，符号怎么排，汉字就怎么念，没有增删任何一个语法零件。甚至把字母也换掉，"甲加乙等于丙"，每一个字都能在公式里找到自己的符号。

英语这边呢？plus 是介词，不是动词，所以 a plus b 只是一个名词短语，不是句子——你单独写下 A plus b.，语法当场报警。它必须硬塞进一个符号里根本不存在的动词 equals，再补上主谓结构，才能勉强合法。**念出来的那一刻，它已经不是公式了，而是一句关于公式的英语句子。**

汉语的运算词——加、减、乘、除、等于、大于、小于——个个都是能直接当谓语的实义动词，正好占据运算符所在的位置，运算符和说出口的词在次序上完全一致。英语的运算符对应词却各有各的语法身份：plus 是介词，squared 是分词，of 是介词，于是朗读时不得不持续地插入和倒装。一个稍复杂的积分：

- 公式：∫₀^∞ e^(−x²) dx = √π / 2
- 汉语：从 0 到无穷大，e 的负 x 平方的积分，等于二分之根号 π
- 英语：The integral from zero to infinity of e to the minus x squared with respect to x equals the square root of pi over two

汉语只是把符号块顺着替换成汉字，遇到分数、积分这种整体，用"分之"、"的积分"一个关系词就收住；英语则层层套上 the、of、from...to...、with respect to，每个名词前都要修冠词，这不是朗读，这是用英语语法把公式重新解释了一遍。

# 总结

把整条逻辑链收束起来：

1. **数学是语义先行的形式系统**：语法极简，符号的定义锁死一切，位置不承担无意义的语法功能。
2. **数学符号是表意符号**：字形直接绑定意义，本质是跨语言的简化字；连字母都被当成了甲乙丙式的占位符。
3. **汉语是自然语言里唯一与这套系统同构的**：表意文字 + 无形态屈折 + 语义先行，让每个运算符都能直译成一个当谓语的汉字，符号和汉字 1:1 映射，结构不变。
4. **英语是表音 + 语法先行的系统**：符号必须先翻译成词，词再被塞进主谓宾、时态、冠词的模具，所以它和数学之间永远隔着一道翻译工序，只能靠"数学英语"这种协和语带病运行。

同构的系统可以直读，不同构的系统只能翻译。**数学公式可以念成汉语，只能翻译成英语**——这不是修辞，是结构事实。

顺带一提，历史也站在这个判断这边。莱布尼茨当年痴迷汉字跨语音、跨方言直接表意的能力，毕生想造一套"通用表意文字"让推理变成符号运算；他在自然语言上失败了，数学符号就是这个梦想在精确领域的局部成功。西方人造出的不是一套新语言，而是一套谁都不用学汉语就能书写的、形式化的汉语子集。[中国人发明了数学](/2023/05/07/chinese-invented-math/) 讲的是十进制和算筹的源流，这一篇讲的是符号的语法——合起来正好是一件事：数学这套东西，从里子到写法，都和汉语是一家人。
